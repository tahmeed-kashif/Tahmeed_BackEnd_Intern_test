### Q3 - REST API
A User Management REST API built using:
- Node.js
- Express.js
- SQLite
- bcrypt

Implemented operations:
- POST /api/users
- GET /api/users
- GET /api/users/:id
- PUT /api/users/:id
- DELETE /api/users/:id

The API includes validation, JSON responses, HTTP status codes, error handling, password hashing, and database persistence.
